## 〇、在线访问（零安装）

不想安装任何东西，直接打开浏览器访问线上环境：

| 用途 | 地址 |
|---|---|
| **应用入口** | https://qingci-cet4-xiuxian.pages.dev/ |
| 健康检查（JSON） | https://qingci-cet4-xiuxian.pages.dev/healthz |
| 状态页（HTML） | https://qingci-cet4-xiuxian.pages.dev/status |
| 元信息（JSON） | https://qingci-cet4-xiuxian.pages.dev/api/meta |

实测（2026-10-03，v1.3.1，每路径 10 次采样 × 2 轮，阈值 2000ms）：**80/80 采样全部返回 HTTP 200 且低于阈值**。
健康检查中位 **235ms** · 元信息中位 **255ms** · 状态页中位 **323ms** · 首页中位 **399ms**。

### 安装到桌面 / 离线使用

线上版本支持安装为独立应用，也能断网使用：

1. **安装**：电脑用 Chrome / Edge 打开线上地址，地址栏右侧点「安装」；
   iPhone / iPad 用 Safari 的「分享 → 添加到主屏幕」。
2. **离线**：首次打开后应用外壳（页面、图标、样式）会被缓存，
   词库与试卷的解析结果存入浏览器 IndexedDB；之后断网也能继续背词与刷题。
3. **更新**：打开页面时若发现新版本，底部会出现「新版本已就绪，点击刷新」，点一下即可切换。
4. **本地文件**：直接双击 `cet4-xiuxian.html` 也能用（离线本来就可用），
   只是不会出现「安装」入口——安装与离线缓存需要 http(s) 环境。

### 无障碍与阅读偏好

1. 「洞府 → 无障碍与阅读偏好」可调：**字号**（标准 / 大 / 特大 / 超大）、
   **高对比度**（弱视友好：纯黑纯白 + 加粗边框）、**减少动态效果**。
2. 三项与主题（浅色 / 深色 / 跟随系统）互相独立，可任意组合；偏好保存在本机浏览器。
3. 字号只放大**题干、选项、解析与听力原文**，导航与按钮保持原样，布局不会被打散。
4. 展开卡片里的「键盘快捷键与朗读说明」可查看完整键位表（也可随时按 `?`）。
5. 键盘党：`1`–`4` 选选项、`←`/`→` 上下题、`Enter` 推进、`空格` 播听力、`R` 重播、`Esc` 关弹窗。
6. 屏幕阅读器：换题会自动朗读题干，正确/错误选项带 ✓/✗ 与文字说明（不只靠颜色），
   弹窗都可用 `Esc` 关闭，焦点始终可见。
### 学业境界、成就称号与道友小组

1. 「洞府 → 学业境界」显示当前境界、双条件进度条（词汇量 / 模考分）、距下一境界还差多少、
   以及瓶颈在词汇还是分数。**两项都达标**才会晋级，且只升不降。
2. 突破时会弹出动画与提示，并写入突破记录（洞府卡片底部可看最近三次）。
3. 「成就称号」列出已解锁与未解锁称号：每条都写明需要做够多少题、正确率多少；
   样本不足不会发放（做 1 题全对不算）。
4. 「道友小组」：填昵称（**请勿填真名、邮箱、手机号或学号**，服务端会拒绝），
   点「开道场」生成 6 位邀请码发给同学；或输入邀请码「入道场」。
5. 榜单可切「本周 / 本月」，只显示 昵称 · 境界 · 进度档 · 学习天数。
   小组内**看不到任何人的分数和答题数据**，进度也只精确到 5%。
6. 小组功能需要服务端配置（见部署说明）；未配置时会提示「本机模式」，学习功能不受影响。

> 设计上刻意避免过度游戏化：没有连续签到惩罚、没有付费加速、不做跳级，
> 所有门槛只能靠真实作答达成；判定在后台完成，不会打断做题。
### 反馈与更新日志

1. 「洞府 → 反馈」打开反馈表单：选择类型、写清问题（越具体越好，例如第几题、哪个按钮、
   期望的行为），可附一张截图（≤512KB），也可留下联系方式。
2. 提交后即时反馈结果：成功 / 内容不合要求 / 提交过于频繁 / 已存本机待重试。
3. **断网也能提**：提交失败会先存在本机（最多 10 条），下次打开页面或网络恢复时自动重试，
   表单右上角显示待提交条数。
4. 提交内容只发往本站的 `/api/feedback`（Cloudflare Pages Function + D1 数据库），
   不经过任何第三方服务；IP 不落库，仅以加盐哈希用于限流。
5. 「洞府 → 更新日志」打开公开更新日志页：按时间倒序展示每个版本的变化，纯静态页，离线也能打开。

### 听力精听

1. 听力题出现后，音频坞里会多一个「精听」按钮，点开进入精听面板。
2. 面板顶部是控制条：播放/暂停、上一句/下一句、循环（关 / 单句 / A-B）、设 A、设 B、清除 A-B、
   语速 0.5×–2×、隐藏原文、听写模式。
3. 中间是逐句列表：点任意一句或「▶ 复读」即可单独反复听；当前句高亮，A-B 区间内的句子左侧有标记。
4. **听写模式**：原文自动隐藏，每句下方出现输入框，输入后回车（或点「比对」），
   会给出匹配率、漏写的词与多写的词。
5. 键盘：← / → 切换句子，空格播放暂停，Esc 关闭面板。

> 目前**没有真实音频素材**，用的是浏览器语音合成占位，时间轴按文本长度估算，
> 面板底部会明确标注「语音合成占位」与「估算时间轴」；A-B 循环按「句」界定。
> 接入真实音频后（提供 url + 逐句时间戳）会显示「真实时间轴」，A-B 按秒精确循环，交互不变。

### 动态学习计划与自适应摸底

1. 「今日功课 → 动态学习计划」可设置**考试日期**与**每日可用时间**（默认 30 分钟），保存后立即重算。
2. 计划会给出：每日新词量、复习量、题型配比（词汇/听力/阅读/写作）、强度（从容/稳步/冲刺）
   与是否「可按期覆盖」；进度条显示词库覆盖、今日新词与今日复习。
3. 下方「近 28 天」热力图按每天的学习量着色，颜色越深练得越多。
4. 点「开始自适应摸底（30–50 题）」进入阶梯测试：答对升难度、答错降难度；
   最少 30 题，若表现极端会提前收敛，最多 50 题。
5. 摸底结束给出**词汇量估计与区间**（例如「约 2600 词（区间 2300–2900），置信度 medium」）、
   各分档掌握率与说明；结果会写回学习进度并据此调整每日目标。
6. 计划会随成绩自动调整：完成率低会减量、正确率低会再降一档、模考卷面分数低会提高听力/阅读配比。

> 摸底是启发式估计（阶梯难度 + 分档加权），不是精确测量；界面会同时给出区间与置信度，
> 提示「题量或分档覆盖不足」时可稍后重测以收窄区间。

### 模考报告与薄弱点

1. 「洞府」页的「模考报告与薄弱点」卡片汇总近 30 天数据：题目数、正确率、最近一次模考各题型得分率。
2. 交卷后自动生成报告：总分与目标分（及格线）差距、还差几题、作答进度、平均每题耗时。
3. 「薄弱点」按 Wilson 下界排序（不是裸正确率），每项显示正确率与样本量；
   少于 3 题的会标为「样本不足」，只提示不推荐，避免被偶然错误带偏。
4. 点「按薄弱点推荐练习」会自动组一份 15 题的练习：主攻最弱方向、混少量其它方向，
   并自动避开最近做过的题；推荐理由会写在按钮右侧。
5. 图表为内联 SVG，跟随深浅色主题；所有报告数据只存在本机浏览器（IndexedDB），
   后续接入账号体系后可同步到云端。

### 词汇间隔复习与分级

1. 「今日功课」页的「词汇间隔复习」卡片显示：计划摘要（距考试天数、强度、今日新词量）、
   四档分级（各档已入列 / 总量）与今日到期数。
2. 点「开始今日复习」只练今天到期的词；点「学新词（按分级）」按 高频 → 核心 → 低频 → 认知词
   的顺序取还没学过的词。
3. 做题时用底部四个按钮反馈：不认识 / 模糊 / 认识 / 熟练 —— 间隔会自动重排
   （忘记 → 今天再练；记得 → 1 天 → 6 天 → 上次间隔 × 难度因子）。
4. 评「不认识」的词会同时进入错题本与心魔；评「认识 / 熟练」则移出心魔。
5. 分级来源会在卡片底部标注：当前为**启发式分级**（词长 / 词缀 / 是否出现在命题材料中），
   不是真实语料词频；接入真实词频表后会自动改标为「真实词频表」。

> 旧版的固定间隔进度（0.25 / 1 / 3 / 7 天）会自动迁移到新的 SM-2 队列，不会丢失。

### 随机练习（避免背答案）

1. 「试炼殿」点「随机练习（20 题）」：首次会联网载入固化题库（约 6 MB，之后本地缓存）。
2. 系统按题型分布与难度区间抽题，并**自动避开你近期做过的题**（300 题窗口）；
   题目由易到难排列，答完自动结束。
3. 答题、判分、错题本与固定卷完全一致；错题会带上题库题目 id，便于在错题本中回看。
4. 六套固定卷仍是模考模式（「开考这一卷」），用于完整计时模拟。

> 题库不可用（离线且从未载入过）时按钮会提示，其他功能不受影响。

### 错题本与今日复习

1. 答错的题会自动进入「心魔 → 错题本」，不需要手动收藏。
2. 点「开始今日复习」只看今天到期的题；再点一次回到全部错题。
3. 点卡片任意位置即可翻转，查看你的答案、正确答案、解析与原文定位；
   底部四个按钮 忘记 / 模糊 / 记得 / 熟练 决定下次复习时间。
4. 题型筛选按钮上会显示各题型的错题数与到期数；下方统计给出按题型分布、
   薄弱知识点与未来 7 天复习量。
5. 换设备或清缓存前，记得在「卷面」页导出 JSON 备份；错题本与学习进度都会一并保留。

> 旧版的「心魔本」单词列表依然保留在同一个页面，并会在首次打开时自动导入错题本
> （只读旧数据，不会修改或删除原有存档）。

### 手机使用、主题与快捷键

- **手机**：选项自动变成全宽卡片（点击区 ≥44px）；听力播放条固定在屏幕底部；
  模考计时器吸顶显示，滚动看题时不会消失。
- **主题**：「洞府 → 外观」可选「跟随系统 / 浅色 / 深色」，默认跟随系统，选择会记住。
- **键盘（桌面）**：

  | 按键 | 作用 |
  |---|---|
  | `1`–`4` | 选择对应选项（选项多于 4 个时最多到 `9`） |
  | `→` / `↓` | 下一题（等价「换题」；已作答时等价「下一题」） |
  | `←` / `↑` | 只读回看上一题，不影响本卷作答与计分 |
  | `Enter` | 提交 / 推进（拼写核对、斗法场下一回合） |
  | `空格` | 播放 / 暂停听力 |

  焦点在输入框或文本框内时以上快捷键自动失效，不会干扰拼写输入。
- **后台播放**：听力开始后可在手机锁屏、通知栏或蓝牙耳机上播放 / 暂停 / 停止。

> 线上与本地打开功能完全一致，学习进度各自保存在你自己的浏览器里，不会上传。

## 二、功能上手指引

### 2.1 选择备考考试与整套突破

在「试炼殿」选择初中英语、高中英语、PETS-3、CET-4 或 CET-6。界面显示该模式的题量、时长、及格线、当前难度和题目来源；点「开考这一卷」完成整套后，只有达到该模式及格线才会触发境界突破。中途交卷会显示当前分数，但不突破。

- 初中、高中、PETS-3、CET-6 当前为**原创练习/原创模拟**，不是真题；CET-4 选择原有六套词库生成模拟卷。
- 难度以当前境界与考试等级计算，范围 1–5；境界提高会逐级提高选词长度与词汇难度。
- 本版本暂未接入经过再利用许可核验的公开真题；界面和元信息会标明原创来源，不将练习题冒充真题。
- 当前其他考试模式使用词汇、词义与轻量语法分类的整套训练；完整阅读篇章、听力录音、写作人工评分尚未覆盖，不能等同正式考试真题卷。

### 2.2 第一次使用：先做词汇摸底

1. 打开页面，首屏「今日功课」卡片点 **开始摸底**
2. 连答 10 题，系统估算你的词汇量
3. 自动生成每日目标（示例：距考试 73 天，建议每日 62 词）
4. 点 **保存目标** 固定下来

### 2.3 背单词：六种题型轮换

顶部导航点 **背单词**：

| 题型 | 你会看到 | 怎么答 |
|---|---|---|
| 中译英 | 中文释义（如「假期」） | 从 4 个英文中选 |
| 英译中 | 英文单词（如 `cream`） | 从 4 个中文中选 |
| 形近辨析 | 中文释义 | 从形近词中选（考拼写细节） |
| 听音辨词 | 🔊 播放提示 | 点「播放听力」后选词 |
| 拼写默写 | 中文 + 首字母提示 `o _ _ _ _ _ _` | 手动输入，回车核对 |
| 词性判断 | 英文单词 | 选出正确词性 |

**切换题型**：在「试炼殿」页面，`立即背词` 旁边有题型下拉框
- 选「题型轮换（推荐）」→ 六种自动交替
- 选具体题型 → 锁定专练（适合针对性补弱）

**记忆反馈**：答完后可点 `不认识 / 模糊 / 认识 / 熟练`，
系统按艾宾浩斯曲线安排下次复习（0.25 / 1 / 3 / 7 天）。

### 2.4 斗法场：把背词变成对战

顶部导航点 **斗法场** → **开始斗法**：

- 每局 5 回合，答对伤敌 **24** 点，答错自损 **18** 点
- 每回合 **15 秒**倒计时，最后 5 秒变红预警，超时视为答错
- 连续答对累积**连击**，答错清零
- 胜出奖励：**30 灵石 + 20 灵气**
- 快捷键：`1–4` 选项，`Enter` 下一题

### 2.5 学情看板：看见自己的进步
页面右侧「学情看板」实时显示：

- **四个数据格**：累计答题 / 正确率 / 已斩获 / 心魔词
- **掌握度环形图**：4540 词中已掌握的比例
- **近 7 日曲线**：折线 + 面积，反映学习节奏
- **题型正确率条**：六种题型逐条对比，哪项弱一目了然
- **灵根（五行天赋）**：由你**各题型的实际正确率**推导，不是随机抽的 ——
  金（拼写）/ 木（中译英）/ 水（听音）/ 火（词性）/ 土（英译中·形近辨析）。
  每系作答满 5 题才会「显现」；只显一系或某系明显占优为**天灵根**，
  两系相当为**双灵根**，依次还有三灵根与杂灵根（杂灵根是特色，不是缺陷）。
  下方会给出**最弱一系的具体目标**与「去练」按钮，点一下直接切到该题型专练。

> 灵根只看**正确率**，不看题量 —— 多刷题不会提高纯度，真正答对才会。

### 2.6 今日功课：三条每日任务

左侧「今日功课」每天刷新三条任务，各自奖励灵石（领取后当天不可重复领）：

| 任务 | 目标 | 奖励 |
|---|---|---|
| **每日背词** | 完成当日目标词数（默认 20 个不重复词） | 30 灵石 |
| **连中三元** | 今日答对 10 题 | 45 灵石 |
| **不息心法** | **今日**最长连对 10 题 | 60 灵石 |

> 「不息心法」看的是**当天**的连对，跨天归零 —— 昨天连对再多也不算今天完成。
> 历史最长连对记录在「成就称号」里（「十连问道」）。
> 答错会中断当前连对，但**当天已达成的最高连对不会被抹掉**。

### 2.7 周天：一周的修行节奏

学情看板下方「周天」把**本周**（周一起算）的 7 天画成一排格子：
有修行记录的那天会亮起，今天额外描边。标题给出本周状态：

| 状态 | 含义 |
|---|---|
| 周天未启 | 本周还没有记录 |
| 周天运转中 x/7 | 已修行 x 天 |
| **周天圆满** | 本周修行满 **5 天**（7 天里做到 5 天即可，**不要求全勤**） |

下方还有一句**与上周的对照**：题量变化，以及（两周题量都够时）正确率变化。

> 周天只看「有没有练」，不看「练了多久」—— 满 5 天即圆满，避免鼓励无效刷时长。
> 上周没有数据时会如实说「这是有记录的第一周」，**不会显示退步**；
> 两周题量都不足 20 题时也不做正确率对照（小样本的百分比会误导人）。
> 周天**不发灵石或修为**，只做呈现与对照。

### 2.8 学习价值：为什么有些词更「值钱」

答对一题给的**修为**不是固定的 —— 它取决于「这次答对对你的学习值多少」：

    实际修为 = 基础分 × 连对倍率 × 学习价值系数

**学习价值系数**由三件事决定：

| 因素 | 规则 |
|---|---|
| **词难度** | 认知词 ×1.5 · 低频 ×1.3 · 核心 ×1.15 · **高频 ×1.0** |
| **新鲜度** | 首次答对 ×1.0 → 第 2 次 ×0.75 → 第 3 次 ×0.55 → 之后 ×0.4 |
| **攻克加成** | 答错过的词，下次答对 ×1.25 |

答题后反馈区会显示 `学习价值 ×1.88` 这样的标签，鼠标悬停可看到原因
（如「已答对 1 次 · 低频词」）。系数为 1.0 时不显示，避免噪声。

**两个刻意的设计：**

1. **高频简单词收益最低** —— 与直觉相反，但是故意的。
   高频词最容易，不该成为刷分对象；认知词最难、最该攻克，收益最高。
2. **复习仍有实在收益（40% 地板）** —— 反复答对同一个词收益递减，
   但**不会降到零**。因为间隔复习本身就是有效学习；
   若复习不值钱，用户会转去刷没见过的词，那是更糟的学习行为。

> 实测差距：**首次攻克认知词 = 刷已掌握高频词的 4.7 倍**。
> 即「刷 20 个简单词」与「攻克 20 个生词」不再等价 —— 收益真正来自学习。

### 2.9 心魔本：专治反复错

答错的词自动进「心魔」，按错误次数排序：

- 点 **只练这些** 进入专注复习
- 商店买 **破障丹（60 灵石）** 清除高频错词

### 2.10 灵石流水：看清每一笔来去

洞府页 → **灵石流水**：近期每一笔灵石的收支都会记在这里，
含中文来源（如「斗法胜出」「购买 · 聚灵阵」）与**变动后余额**。

背词、每日任务、斗法、渡劫、奇遇、灵田收获、传功、道场捐献、商店购买
都会入账 —— 若觉得灵石对不上，看这里最快。

### 2.11 奇遇与道场：修行中的意外收获

- **奇遇**：答题过程中会随机触发（每日上限 2 次），点「领取」真正生效 ——
  **洞天福地**（1 小时修为 ×1.5）、**灵兽来投**（永久修为 ×1.1）、
  **老道指点**（当日重点词额外 +10）、**拾得残卷**（解锁某词深度解析）、
  **心魔来袭**（直接开一组心魔复习）、**灵石雨**（+30~80 灵石）。
  生效中的增益会常驻显示在左侧「修为」卡下方。
- **道场建设**（洞府页）：捐献灵石建成设施后，全道场共享增益 ——
  **藏经阁**（参悟古籍 -20%）、**炼丹房**（每月 1 张护道符）、
  **演武场**（论剑胜率 +5%）。
- **洞府装饰**：买下的装饰会真的改变界面（水墨底色、竹影、称号框、头像框）。

### 2.12 数据备份（重要）

洞府页 → **导出** 保存为 JSON；换设备时 **导入** 恢复。

> ⚠️ 清理浏览器缓存仍会丢失进度，建议**每周导出一次**。

>
> 「散功」会同时清空修行录与上述全部本地数据，**不可撤销** —— 请先导出备份。

## 三、常见问题

**Q：打不开 / 白屏？**
检查是否用了旧版 IE。建议 Chrome 90+ / Edge 90+ / Safari 14+。

**Q：听力没声音？**
浏览器语音合成依赖系统语音包。若无声，可改看音标（题面下方已给出）。

**Q：进度不见了？**
多为清缓存或无痕模式导致。用「导入」恢复备份。

**Q：题目是真题吗？**
**不是。** 模拟卷是按 CET-4 结构用词库生成的练习卷，页面已标注。

**Q：能离线用吗？**
可以。单文件自包含，零外部依赖，断网照常使用（听力除外，需系统语音包）。
