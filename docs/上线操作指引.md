# 上线操作指引（Cloudflare Workers）

当前状态：**代码与部署链路已就绪，仅差一步账号授权。**

## 为什么需要你操作

部署到 Cloudflare 需要账号授权（OAuth 登录或 API Token），这属于只有账号本人能完成的动作。
其余工作（Worker 代码、wrangler 配置、构建打包、部署脚本、验收脚本、文档）都已就绪。

## 方案 A：OAuth 登录（推荐，一次授权长期有效）

在项目目录执行：

```bash
cd qingci-cet4-xiuxian
npx wrangler login
```

浏览器会弹出 Cloudflare 授权页，点 **Allow** 即可。

授权成功后执行一键部署：

```bash
npm run deploy
```

## 方案 B：API Token（免浏览器，适合服务器环境）

1. 打开 https://dash.cloudflare.com/profile/api-tokens
2. 点 **Create Token** → 选模板 **Edit Cloudflare Workers** → **Continue to summary** → **Create Token**
3. 复制生成的 Token，然后：

```bash
cd qingci-cet4-xiuxian
set CLOUDFLARE_API_TOKEN=你的Token
npm run deploy
```

## 部署后会发生什么

`npm run deploy` 会自动：

1. 构建产物（`dist/cet4-xiuxian.html`，含 4540 词库）
2. 生成 Workers 版部署目录 `deploy/`
3. 同步版本号到 `wrangler.toml`
4. 上传到 Cloudflare 边缘网络
5. **把正式地址写入 `deploy-url.txt`**

Worker 名称 `qingci-cet4-xiuxian` 搭配你的子域 `bw8pbrkt56`，
预期地址为：

```text
应用入口   https://qingci-cet4-xiuxian.bw8pbrkt56.workers.dev/
健康检查   https://qingci-cet4-xiuxian.bw8pbrkt56.workers.dev/healthz
元信息     https://qingci-cet4-xiuxian.bw8pbrkt56.workers.dev/api/meta
状态页     https://qingci-cet4-xiuxian.bw8pbrkt56.workers.dev/status
```

部署完成后执行采样验收（每路径 10 次，统计 200 比例与耗时）：

```bash

```

## 常见问题

**Q：报错 `You are not authenticated`**
未登录。执行 `npx wrangler login`，或设置 `CLOUDFLARE_API_TOKEN`。

**Q：报错 `_redirects` 无限循环告警**
已修复：Workers 模式不再生成 `_redirects`（该文件仅用于 Pages/Netlify 等纯静态托管）。

**Q：地址能固定不变吗**
能。Workers 地址是永久固定的 `*.workers.dev` 子域，不像临时隧道每次重启就变。
