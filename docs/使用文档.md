## 〇、在线访问（零安装）

不想安装任何东西，直接打开浏览器访问线上环境：

| 用途 | 地址 |
|---|---|
| **应用入口** | https://qingci-cet4-xiuxian.pages.dev/ |
| 健康检查（JSON） | https://qingci-cet4-xiuxian.pages.dev/healthz |
| 状态页（HTML） | https://qingci-cet4-xiuxian.pages.dev/status |
| 元信息（JSON） | https://qingci-cet4-xiuxian.pages.dev/api/meta |

实测（2026-10-03，v1.3.1，每路径 10 次采样 × 2 轮，阈值 2000ms）：**80/80 采样全部返回 HTTP 200 且低于阈值**。
健康检查中位 **235ms** · 元信息中位 **255ms** · 状态页中位 **323ms** · 首页中位 **399ms**。

### 安装到桌面 / 离线使用

线上版本支持安装为独立应用，也能断网使用：

1. **安装**：电脑用 Chrome / Edge 打开线上地址，地址栏右侧点「安装」；
   iPhone / iPad 用 Safari 的「分享 → 添加到主屏幕」。
2. **离线**：首次打开后应用外壳（页面、图标、样式）会被缓存，
   词库与试卷的解析结果存入浏览器 IndexedDB；之后断网也能继续背词与刷题。
3. **更新**：打开页面时若发现新版本，底部会出现「新版本已就绪，点击刷新」，点一下即可切换。
4. **本地文件**：直接双击 `cet4-xiuxian.html` 也能用（离线本来就可用），
   只是不会出现「安装」入口——安装与离线缓存需要 http(s) 环境。

### 动态学习计划与自适应摸底

1. 「今日功课 → 动态学习计划」可设置**考试日期**与**每日可用时间**（默认 30 分钟），保存后立即重算。
2. 计划会给出：每日新词量、复习量、题型配比（词汇/听力/阅读/写作）、强度（从容/稳步/冲刺）
   与是否「可按期覆盖」；进度条显示词库覆盖、今日新词与今日复习。
3. 下方「近 28 天」热力图按每天的学习量着色，颜色越深练得越多。
4. 点「开始自适应摸底（30–50 题）」进入阶梯测试：答对升难度、答错降难度；
   最少 30 题，若表现极端会提前收敛，最多 50 题。
5. 摸底结束给出**词汇量估计与区间**（例如「约 2600 词（区间 2300–2900），置信度 medium」）、
   各分档掌握率与说明；结果会写回学习进度并据此调整每日目标。
6. 计划会随成绩自动调整：完成率低会减量、正确率低会再降一档、模考卷面分数低会提高听力/阅读配比。

> 摸底是启发式估计（阶梯难度 + 分档加权），不是精确测量；界面会同时给出区间与置信度，
> 提示「题量或分档覆盖不足」时可稍后重测以收窄区间。

### 模考报告与薄弱点

1. 「洞府」页的「模考报告与薄弱点」卡片汇总近 30 天数据：题目数、正确率、最近一次模考各题型得分率。
2. 交卷后自动生成报告：总分与目标分（及格线）差距、还差几题、作答进度、平均每题耗时。
3. 「薄弱点」按 Wilson 下界排序（不是裸正确率），每项显示正确率与样本量；
   少于 3 题的会标为「样本不足」，只提示不推荐，避免被偶然错误带偏。
4. 点「按薄弱点推荐练习」会自动组一份 15 题的练习：主攻最弱方向、混少量其它方向，
   并自动避开最近做过的题；推荐理由会写在按钮右侧。
5. 图表为内联 SVG，跟随深浅色主题；所有报告数据只存在本机浏览器（IndexedDB），
   后续接入账号体系后可同步到云端。

### 词汇间隔复习与分级

1. 「今日功课」页的「词汇间隔复习」卡片显示：计划摘要（距考试天数、强度、今日新词量）、
   四档分级（各档已入列 / 总量）与今日到期数。
2. 点「开始今日复习」只练今天到期的词；点「学新词（按分级）」按 高频 → 核心 → 低频 → 认知词
   的顺序取还没学过的词。
3. 做题时用底部四个按钮反馈：不认识 / 模糊 / 认识 / 熟练 —— 间隔会自动重排
   （忘记 → 今天再练；记得 → 1 天 → 6 天 → 上次间隔 × 难度因子）。
4. 评「不认识」的词会同时进入错题本与心魔；评「认识 / 熟练」则移出心魔。
5. 分级来源会在卡片底部标注：当前为**启发式分级**（词长 / 词缀 / 是否出现在命题材料中），
   不是真实语料词频；接入真实词频表后会自动改标为「真实词频表」。

> 旧版的固定间隔进度（0.25 / 1 / 3 / 7 天）会自动迁移到新的 SM-2 队列，不会丢失。

### 随机练习（避免背答案）

1. 「试炼殿」点「随机练习（20 题）」：首次会联网载入固化题库（约 6 MB，之后本地缓存）。
2. 系统按题型分布与难度区间抽题，并**自动避开你近期做过的题**（300 题窗口）；
   题目由易到难排列，答完自动结束。
3. 答题、判分、错题本与固定卷完全一致；错题会带上题库题目 id，便于在错题本中回看。
4. 六套固定卷仍是模考模式（「开考这一卷」），用于完整计时模拟。

> 题库不可用（离线且从未载入过）时按钮会提示，其他功能不受影响。

### 错题本与今日复习

1. 答错的题会自动进入「心魔 → 错题本」，不需要手动收藏。
2. 点「开始今日复习」只看今天到期的题；再点一次回到全部错题。
3. 点卡片任意位置即可翻转，查看你的答案、正确答案、解析与原文定位；
   底部四个按钮 忘记 / 模糊 / 记得 / 熟练 决定下次复习时间。
4. 题型筛选按钮上会显示各题型的错题数与到期数；下方统计给出按题型分布、
   薄弱知识点与未来 7 天复习量。
5. 换设备或清缓存前，记得在「卷面」页导出 JSON 备份；错题本与学习进度都会一并保留。

> 旧版的「心魔本」单词列表依然保留在同一个页面，并会在首次打开时自动导入错题本
> （只读旧数据，不会修改或删除原有存档）。

### 手机使用、主题与快捷键

- **手机**：选项自动变成全宽卡片（点击区 ≥44px）；听力播放条固定在屏幕底部；
  模考计时器吸顶显示，滚动看题时不会消失。
- **主题**：「洞府 → 外观」可选「跟随系统 / 浅色 / 深色」，默认跟随系统，选择会记住。
- **键盘（桌面）**：

  | 按键 | 作用 |
  |---|---|
  | `1`–`4` | 选择对应选项（选项多于 4 个时最多到 `9`） |
  | `→` / `↓` | 下一题（等价「换题」；已作答时等价「下一题」） |
  | `←` / `↑` | 只读回看上一题，不影响本卷作答与计分 |
  | `Enter` | 提交 / 推进（拼写核对、斗法场下一回合） |
  | `空格` | 播放 / 暂停听力 |

  焦点在输入框或文本框内时以上快捷键自动失效，不会干扰拼写输入。
- **后台播放**：听力开始后可在手机锁屏、通知栏或蓝牙耳机上播放 / 暂停 / 停止。

> 线上与本地打开功能完全一致，学习进度各自保存在你自己的浏览器里，不会上传。

## 二、功能上手指引

### 2.1 选择备考考试与整套突破

在「试炼殿」选择初中英语、高中英语、PETS-3、CET-4 或 CET-6。界面显示该模式的题量、时长、及格线、当前难度和题目来源；点「开考这一卷」完成整套后，只有达到该模式及格线才会触发境界突破。中途交卷会显示当前分数，但不突破。

- 初中、高中、PETS-3、CET-6 当前为**原创练习/原创模拟**，不是真题；CET-4 选择原有六套词库生成模拟卷。
- 难度以当前境界与考试等级计算，范围 1–5；境界提高会逐级提高选词长度与词汇难度。
- 本版本暂未接入经过再利用许可核验的公开真题；界面和元信息会标明原创来源，不将练习题冒充真题。
- 当前其他考试模式使用词汇、词义与轻量语法分类的整套训练；完整阅读篇章、听力录音、写作人工评分尚未覆盖，不能等同正式考试真题卷。

### 2.2 第一次使用：先做词汇摸底

1. 打开页面，首屏「今日功课」卡片点 **开始摸底**
2. 连答 10 题，系统估算你的词汇量
3. 自动生成每日目标（示例：距考试 73 天，建议每日 62 词）
4. 点 **保存目标** 固定下来

### 2.2 背单词：六种题型轮换

顶部导航点 **背单词**：

| 题型 | 你会看到 | 怎么答 |
|---|---|---|
| 中译英 | 中文释义（如「假期」） | 从 4 个英文中选 |
| 英译中 | 英文单词（如 `cream`） | 从 4 个中文中选 |
| 形近辨析 | 中文释义 | 从形近词中选（考拼写细节） |
| 听音辨词 | 🔊 播放提示 | 点「播放听力」后选词 |
| 拼写默写 | 中文 + 首字母提示 `o _ _ _ _ _ _` | 手动输入，回车核对 |
| 词性判断 | 英文单词 | 选出正确词性 |

**切换题型**：在「试炼殿」页面，`立即背词` 旁边有题型下拉框
- 选「题型轮换（推荐）」→ 六种自动交替
- 选具体题型 → 锁定专练（适合针对性补弱）

**记忆反馈**：答完后可点 `不认识 / 模糊 / 认识 / 熟练`，
系统按艾宾浩斯曲线安排下次复习（0.25 / 1 / 3 / 7 天）。

### 2.3 斗法场：把背词变成对战

顶部导航点 **斗法场** → **开始斗法**：

- 每局 5 回合，答对伤敌 **24** 点，答错自损 **18** 点
- 每回合 **15 秒**倒计时，最后 5 秒变红预警，超时视为答错
- 连续答对累积**连击**，答错清零
- 胜出奖励：**30 灵石 + 20 灵气**
- 快捷键：`1–4` 选项，`Enter` 下一题

### 2.4 学情看板：看见自己的进步

页面右侧「学情看板」实时显示：

- **四个数据格**：累计答题 / 正确率 / 已斩获 / 心魔词
- **掌握度环形图**：4540 词中已掌握的比例
- **近 7 日曲线**：折线 + 面积，反映学习节奏
- **题型正确率条**：六种题型逐条对比，哪项弱一目了然

### 2.5 心魔本：专治反复错

答错的词自动进「心魔」，按错误次数排序：

- 点 **只练这些** 进入专注复习
- 商店买 **破障丹（60 灵石）** 清除高频错词

### 2.6 数据备份（重要）

洞府页 → **导出** 保存为 JSON；换设备时 **导入** 恢复。

> ⚠️ 清理浏览器缓存会丢失进度，建议每周导出一次。

## 三、常见问题

**Q：打不开 / 白屏？**
检查是否用了旧版 IE。建议 Chrome 90+ / Edge 90+ / Safari 14+。

**Q：听力没声音？**
浏览器语音合成依赖系统语音包。若无声，可改看音标（题面下方已给出）。

**Q：进度不见了？**
多为清缓存或无痕模式导致。用「导入」恢复备份。

**Q：题目是真题吗？**
**不是。** 模拟卷是按 CET-4 结构用词库生成的练习卷，页面已标注。

**Q：能离线用吗？**
可以。单文件自包含，零外部依赖，断网照常使用（听力除外，需系统语音包）。

## 五、命令速查

```bash
npm start               # 启动本地服务（默认 127.0.0.1:4173）
npm run build           # 构建发布产物到 dist/
npm test                # 运行 151 个自动化测试
npm run test:coverage   # 测试 + 覆盖率报告
npm run healthcheck     # 对已启动服务做健康检查
npm run deploy:pages    # 一键部署到 Cloudflare Pages（当前线上入口）
npm run deploy          # 一键部署到 Cloudflare Workers
npm run probe:prod      # 线上采样验收（每路径 5 次，阈值 2000ms）
npm run verify          # 一键：构建 + 测试 + 本地健康检查
```

> **关于线上可用性**：当前线上入口为 Cloudflare Pages 的固定域名
> `https://qingci-cet4-xiuxian.pages.dev`。它与本机是否开机无关
> （静态资源托管在边缘网络），不需要保活进程。
>
> 早前版本曾用免账号 Cloudflare 隧道做临时演示，该方案已被弃用：
> 隧道地址每次重启都会变化，且回源本机，本机关机即不可访问。
