### 两处需要说明的「不算缺陷」

审计中这三类现象一度被判为 FAIL，核对源码后确认是**判定口径问题，不是代码缺陷**，
已在校验脚本中修正口径并注明原因，避免后来者重复踩坑：

1. **图表 SVG 不该套用装饰性图标规则。**
   掌握度环（`viewBox="0 0 120 120"`）、七日趋势线（`0 0 280 64`）、
   模考图表都带 `aria-label` 且按自身坐标绘制。把它们 `aria-hidden`
   反而会让读屏用户丢失图表信息。它们不是装饰图标，规则不适用。

2. **运行时拼接的 SVG 静态扫描看不到。**
   道场图标是 `'<svg ' + common + '>'` 拼出来的，静态标记里只有半截 `<svg`。
   回到模板核对 `var common`（`index.template.html:1229`），
   确认 `aria-hidden="true"` 与 `focusable="false"` 都在，24 网格也在。

3. **祖先 `aria-hidden` 是等效写法。**
   道场图标写作 `<span class="fac-art" aria-hidden="true"><svg …></svg></span>`，
   由父元素承担隐藏。审计脚本已支持「祖先已隐藏」这一等价判定。

### C3-5 · 唯一遗留项

组件样式里仍有 **7 处**裸 hex 色值，分布在
`.skip-link`、`.err-banner code`、`.duel-choice:hover .key`、`.duel-hp i`、
`.foe .duel-hp i`、`.brand-mark`、`.mission .mini-bar i`。

**这不是 v1.8.1 引入的。** 逐版本回查：

| 版本 | `.brand-mark` | `.skip-link` | `.foe .duel-hp i` |
|---|---|---|---|
| v1.7.0 | 已存在 | 已存在 | 已存在 |
| v1.8.0 | 已存在 | 已存在 | 已存在 |
| v1.8.1 | 已存在 | 已存在 | 已存在 |

并且 `git diff cfd495d~1 cfd495d` 中，**v1.8.1 新增行的 hex 色值数量为 0** ——
谕令三「新增样式零硬编码色值」这句话对 v1.8.1 自身是**成立的**，
只是全站存量仍有 v1.7.0 之前的老债。

**建议（不在本次执行，留给下一版）：**
把这 7 处收进既有 token，特别是 `.brand-mark` 的 `#f8f3ea` /
`#12866b` / `#0a4a3a` 其实与 `--solid-fg` 和 `--jade` 系完全对应，
`.foe .duel-hp i` 的 `#e08a63` 建议新增一个 `--foe` token。
改完 C3-5 即可由 LEGACY 转 PASS。

### C3-7 · 一处需要说明的判定

初判时 `bt-spin` / `bt-pulse` 被算作常驻循环动效，核对 CSS 级联后发现不对：

- `.bt-ring` 先声明 `animation:bt-spin 6s linear infinite`（样式表 L165）
- 后面又被 `.bt-ring{animation:bt-spin 3.6s … 1 both}` 覆盖（L430）

**后置声明胜出**，最终效果是限 3 次即止，不是常驻动效。
`.bt-ring::after` 同理被 L431 的 `3 both` 覆盖。
告警脉冲 `timerPulse` / `tribTimerPulse` 仅在告警 class 挂载时才出现。
故全场常驻装饰动效确实只有成熟灵植呼吸 `plotBreath` 一处，**谕令声明属实**。

审计脚本已改为「按选择器聚合、取最后一次声明」后再统计，
这是唯一正确的 CSS cascade 语义。

## 终验小结

1. **四条谕令的声明全部属实，无虚报。** 29 项验收全过，唯一一条
   不完全达标的 C3-5 经版本回查确认为 v1.7.0 之前的历史遗留，
   与 v1.8.1 无关。

2. **真正影响用户数据安全的两条都守住了**：
   C1-5（灵田底层语义未动）与 C4-6（realmIndex 缺省即旧行为）。
   这两条决定了 v1.8.1 升级会不会弄坏老用户的既有进度。

3. **零外部依赖守住了**：24 处图标全内联，无 font-awesome /
   material-icons / 外链图片，与叁「单文件自包含」一致。

4. **无障碍没有因为图标重绘而丢失**：装饰图标全部 aria-hidden，
   而图表 SVG 保留了 aria-label —— 这两者的区分是正确的，
   把图表也隐藏反而是倒退。

**留待下一版处理**：C3-5 的 7 处存量硬编码色值（v1.7.0 之前的老债）。
