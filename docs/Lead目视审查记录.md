## 二、目视发现的具体问题（按严重度）

### 🔴 P0 — `#panel-missions` 常驻可见，占据**每一个**面板的顶部

实测：`panel-missions` **没有 `hidden` 类**，且**不在 `switchTab` 的列表**里
（列表是 `["paper","trial","speak","book","codex","map","duel","field"]`）。

后果：用户在试炼殿/背单词/口语/心魔/词谱/洞府/灵田/斗法 —— **8 个面板中的任何一个**，
顶部都压着「每日修炼设置」（含每日背词目标输入框 + 保存按钮 + 动态学习计划 + SM-2 复习卡）。

这是「界面很混乱」的**最大单一原因**：一个不该常驻的设置区出现在所有页面顶部。

**建议**：把它改成真正的面板（加进 `switchTab` 列表），或折叠为默认收起的 `<details>`。
⚠️ 注意：`tests/` 里可能有断言依赖它在 `panel-missions` 内（改前先 grep）。

### 🔴 P1 — 洞府页「当前词库」8 卡片大网格占满首屏

截图 `map-dark-1440.png` 显示：首屏几乎全是 8 张词库卡（初中/高中/CET-4/CET-6/考研/GRE/IELTS/TOEFL），
每张都含「图标 + 标题 + 4 行说明 + 切换按钮」。

问题：① 信息密度极高；② 每张卡都有边框（贡献 8 个边框组）；
③ 「切换」按钮视觉权重过低，与卡片体积不匹配。

**建议**：默认只显示当前词库 + 「更换词库」按钮，展开后才是网格；
或改为下拉选择器 + 当前词库摘要。

### 🟡 P2 — 纹饰过密（**根因已更正 —— 我最初的判断是错的**）

> ⚠️ **更正说明**：我最初写「因为 v1.12 把回纹边+如意角加到每个 `.panel`/`.shop-card`」——
> **这是错的**，由 ui-batch2 子代理指出并经我独立复核确认：
> 回纹/如意角走 `.panel::before` / `::after` 的 `background` + `mask`，
> **`border` 为 0**，且**伪元素进不了 `querySelectorAll('*')`** —— 本指标根本不统计它们。
> 实测：`pseudoBeforeBorder = 0px`，而 `panelRealBorder = 1px`。
> 所以「去掉 `.shop-card` 边框」对指标收益 ≈ 0。

### 🟡 P2（更正后）— 指标口径问题

原口径把**按钮/输入框的边框**也算进「边框组」，于是「降噪」会去动 `.btn{border}`。
但按钮边框是**可点击性的功能提示** —— 为了一个自设指标去改它是本末倒置。

**v2 起 `audit:ui` 改为分开度量**（见 `scripts/audit-ui.mjs` 顶部说明）：
- **容器边框** = 装饰/结构容器 ← 真正的噪声指标，目标 ≤5
- **控件边框** = button/input/select ← 只报告，**不设阈值**
