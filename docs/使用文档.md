适用版本：**v1.0.5** ｜ 更新日期：2026-09-30

## 一、三种使用方式

### 方式 A：直接打开（最简单，推荐普通用户）

双击 `dist/cet4-xiuxian.html`，用浏览器打开即可。

- 无需安装、无需联网、无需账号
- 进度保存在浏览器本地（localStorage）
- **注意**：不要用微信/QQ 内置浏览器打开，建议 Chrome / Edge / Safari

### 方式 B：本地服务（推荐开发与演示）

```bash
npm start
```

启动后访问提示的地址（默认 `http://127.0.0.1:4173`）。

实际输出：

```text
✅ 服务已启动
   地址: http://127.0.0.1:4173
   健康检查: http://127.0.0.1:4173/healthz
   应用来源: dist
   版本: v1.0.5
```

### 方式 C：从源码构建（推荐二次开发）

```bash
npm install     # 安装依赖（本项目零外部依赖，秒完成）
npm run build   # 构建
npm test        # 跑测试
```

实际输出：


## 二、功能上手指引

### 2.1 第一次使用：先做词汇摸底

1. 打开页面，首屏「今日功课」卡片点 **开始摸底**
2. 连答 10 题，系统估算你的词汇量
3. 自动生成每日目标（示例：距考试 73 天，建议每日 62 词）
4. 点 **保存目标** 固定下来

### 2.2 背单词：六种题型轮换

顶部导航点 **背单词**：

| 题型 | 你会看到 | 怎么答 |
|---|---|---|
| 中译英 | 中文释义（如「假期」） | 从 4 个英文中选 |
| 英译中 | 英文单词（如 `cream`） | 从 4 个中文中选 |
| 形近辨析 | 中文释义 | 从形近词中选（考拼写细节） |
| 听音辨词 | 🔊 播放提示 | 点「播放听力」后选词 |
| 拼写默写 | 中文 + 首字母提示 `o _ _ _ _ _ _` | 手动输入，回车核对 |
| 词性判断 | 英文单词 | 选出正确词性 |

**切换题型**：在「试炼殿」页面，`立即背词` 旁边有题型下拉框
- 选「题型轮换（推荐）」→ 六种自动交替
- 选具体题型 → 锁定专练（适合针对性补弱）

**记忆反馈**：答完后可点 `不认识 / 模糊 / 认识 / 熟练`，
系统按艾宾浩斯曲线安排下次复习（0.25 / 1 / 3 / 7 天）。

### 2.3 斗法场：把背词变成对战

顶部导航点 **斗法场** → **开始斗法**：

- 每局 5 回合，答对伤敌 **24** 点，答错自损 **18** 点
- 每回合 **15 秒**倒计时，最后 5 秒变红预警，超时视为答错
- 连续答对累积**连击**，答错清零
- 胜出奖励：**30 灵石 + 20 灵气**
- 快捷键：`1–4` 选项，`Enter` 下一题

### 2.4 学情看板：看见自己的进步

页面右侧「学情看板」实时显示：

- **四个数据格**：累计答题 / 正确率 / 已斩获 / 心魔词
- **掌握度环形图**：4540 词中已掌握的比例
- **近 7 日曲线**：折线 + 面积，反映学习节奏
- **题型正确率条**：六种题型逐条对比，哪项弱一目了然

### 2.5 心魔本：专治反复错

答错的词自动进「心魔」，按错误次数排序：

- 点 **只练这些** 进入专注复习
- 商店买 **破障丹（60 灵石）** 清除高频错词

### 2.6 数据备份（重要）

洞府页 → **导出** 保存为 JSON；换设备时 **导入** 恢复。

> ⚠️ 清理浏览器缓存会丢失进度，建议每周导出一次。

## 三、常见问题

**Q：打不开 / 白屏？**
检查是否用了旧版 IE。建议 Chrome 90+ / Edge 90+ / Safari 14+。

**Q：听力没声音？**
浏览器语音合成依赖系统语音包。若无声，可改看音标（题面下方已给出）。

**Q：进度不见了？**
多为清缓存或无痕模式导致。用「导入」恢复备份。

**Q：题目是真题吗？**
**不是。** 模拟卷是按 CET-4 结构用词库生成的练习卷，页面已标注。

**Q：能离线用吗？**
可以。单文件自包含，零外部依赖，断网照常使用（听力除外，需系统语音包）。

## 四、快捷键

| 按键 | 作用 |
|---|---|
| `1–9` | 选择对应选项 |
| `Enter` | 下一题 |
| `Space` | 播放当前听力 |
| `1–4` + `Enter` | 斗法场作答与推进 |

> 快捷键在输入框内自动失效，不会干扰拼写输入。

## 五、命令速查

```bash
npm start           # 启动本地服务（默认 127.0.0.1:4173）
npm run build       # 构建发布产物到 dist/
npm test            # 运行 30 个自动化测试
npm run test:coverage   # 测试 + 覆盖率报告
npm run test:docs   # 核验 API 文档 26 条示例可执行
npm run healthcheck # 对已启动服务做健康检查
npm run watchdog    # 公网在线巡检（延迟超 2 秒即报错退出）
npm run keepalive   # 公网保活（常驻心跳，防止隧道休眠冷启动）
npm run verify      # 一键：构建 + 测试 + 文档核验 + 本地健康检查
npm run verify:prod # 公网端到端验收：测试 + 文档核验 + 在线巡检
```
