## 一、目标用户画像

### 主画像：备考型在校生（占比预估 70%）

| 维度 | 描述 |
|---|---|
| 身份 | 大一/大二本科生，非英语专业，需通过 CET-4 才能毕业或拿学位 |
| 目标 | 在 2026-12-12 笔试前把词汇量从约 2000 提到 4500+ |
| 痛点 | ① 背词 app 打卡 7 天就放弃——缺即时反馈；② 只认得单词但拼不出；③ 不知道自己的时间花在哪 |
| 使用场景 | 宿舍碎片时间（10–20 分钟/次），手机为主，偶尔电脑 |
| 技术水平 | 普通用户，不会配置环境、不会装插件 |
| 关键诉求 | **打开就能用，进度不丢，能看见自己在进步** |

### 副画像：二战/冲刺型考生（20%）

- 已考过一次，分数卡在 400–424 之间
- 需求从"认词"转为"精准补漏"：知道自己哪些词反复错
- 需要**心魔本**（错题归集）与**题型正确率**定位薄弱环节

### 边缘画像：英语兴趣学习者 / 教师演示（10%）

- 不为考试，单纯喜欢游戏化学习
- 教师用于课堂演示词汇量分布

### 用户不做的事（明确排除）

- 不需要社交、排行榜、账号体系（本版本纯本地，无隐私顾虑）
- 不需要真题（版权风险，且本产品定位为词汇训练，非押题）
- 不需要移动 App 安装包（单文件网页已满足，降低获取门槛）

### 2.2 六种记忆题型设计（核心差异化）

每种题型针对一条记忆通道，避免"只认脸"的假性掌握：

| 题型 | 记忆通道 | 交互 | 设计意图 |
|---|---|---|---|
| **中译英** | 义 → 形 | 4 选 1 | 主动产出，检验能否由意思想起拼写 |
| **英译中** | 形 → 义 | 4 选 1 | 阅读向，检验认词速度 |
| **形近辨析** | 拼写细节 | 4 选 1（干扰项取同前缀/同长度词） | 专治 apply/application 类混淆 |
| **听音辨词** | 语音 | 浏览器朗读后选词 | 补听力短板，音形联结 |
| **拼写默写** | 主动产出 | 输入字母，首字母+下划线提示 | 唯一"从零写出来"的题型，杜绝蒙对 |
| **词性判断** | 语法 | 4 选 1（名词/动词/形容词…） | 写作与语法填空的基础 |

**为什么是六种**：认词（2）+ 辨形（1）+ 听音（1）+ 产出（1）+ 语法（1）覆盖了
"看到能懂、听到能认、想到能写、用起来不别扭"的完整链路。

### 2.3 游戏化机制

- **境界体系**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 地仙
- **灵气**：答对获得（含连击加成），累积提升境界
- **灵石**：完成每日任务、对战胜出获得，可在商店兑换
- **每日任务**：每日背词量 / 连中三元 / 不息心法
- **成就**：初入词海、十连问道、百词斩、开卷有益、心魔尽斩

## 三、技术架构

![架构图](./architecture.png)

### 3.1 架构特点

**单文件自包含**是核心工程决策：

| 决策 | 理由 | 代价 |
|---|---|---|
| 全部 CSS/JS 内联，零 CDN | 用户断网、换电脑、发同事都能打开 | 文件较大（463 KB） |
| 词库 JSON 内嵌 | 免网络请求，秒开 | 词库扩展需重新构建 |
| 数据存 localStorage | 无服务端，无隐私风险，零运维 | 换设备需手动导出导入 |
| 核心逻辑抽 `src/core/` | 可被 Node 测试覆盖，保证质量 | 需构建步骤同步 |

### 3.2 模块划分

```text
src/core/utils.js   纯工具：哈希、确定性随机、间隔重复、境界、统计换算
src/core/quiz.js    业务核心：六种题型生成、判分、题型统计
src/index.template.html   应用外壳：DOM 渲染、交互、localStorage
scripts/build.mjs   构建：完整性校验 → 注入版本 → 输出 dist
server.mjs          HTTP 服务：静态托管 + /healthz 健康检查
tests/*.test.js     自动化测试：node:test，30 用例
```

### 3.3 关键技术选型

- **确定性随机（mulberry32 + FNV-1a 哈希）**：同一套卷子每次题序一致，便于"重做对比上次"
- **纯函数核心逻辑**：`recordMemStat` 等返回新对象而非改原值，便于测试与状态回溯
- **无构建依赖**：构建脚本仅用 Node 内置模块，`npm install` 后零外部依赖，规避供应链风险
- **容错保护**：看板渲染包 try/catch，旧存档缺字段时静默降级，不连累主流程

### 3.4 性能指标

| 指标 | 实测值 |
|---|---|
| 构建产物 | 463.9 KB（单文件） |
| 健康检查响应 | **12ms**（阈值 2000ms） |
| 页面首屏渲染 | 无网络请求，本地即时 |
| 测试执行 | 30 用例 / 87ms |

## 五、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 词库例句缺失，记忆深度有限 | 中等 | v1.1 优先补齐，这是提升学习效果的最高杠杆 |
| 单文件 463 KB，低端机加载慢 | 低 | 实测本地打开无网络延迟，可接受 |
| localStorage 清缓存丢进度 | 中 | 已提供导出/导入 JSON，建议提示用户定期备份 |
| 浏览器语音合成音色不一 | 低 | 已有"听音辨词"降级为可直接看音标 |
| 模拟卷非真题 | 低 | 页面已明确标注"练习卷，不是历年真题" |
